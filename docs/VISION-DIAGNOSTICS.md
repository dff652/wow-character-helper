# 本地识别诊断 0.2.0 预览

本轮补读与留出截图结果见 [OCR-EVALUATION.md](OCR-EVALUATION.md)。尚不能依赖 OCR 自动确认名字或提交角色。

## 0.1.0 基础能力和历史验证

开发分支：`feature/character-vision-diagnostics`。这是通用识别改造的第一阶段，不是已完成的通用建号引擎。

## 使用

运行独立的 `CharacterVision.exe`，与旧版 `RetryPvp.exe` 分开。保留旁边的 `recognize-image.ps1` 和配置文件。

- 导入截图：本地 OCR 后显示文字框、原文和页面/角色候选。
- 读取前台游戏：点击后有 3 秒倒计时，手动切到游戏；只读取前台 Wow.exe 的可见客户区，不激活窗口、不点击、不输入、不提交。
- 打开诊断记录：查看每次的 `report.json`、`summary.txt`、OCR 输入和标注图，位于程序目录 `data/diagnostics/`。

依赖 64 位 Windows、.NET Framework 4.8、系统 Windows PowerShell 和已安装的中文 Windows OCR。此版本不联网，不需要大模型 API 密钥。

## 技术与边界

OCR 返回文字与坐标；缩小图像后将文字框映射回原图。页面候选基于文字证据，右侧独立标题与全页出现的词分别展示。姓名候选按当前无限服顶部双输入框的相对区域读取，不包含预设姓名模板。

相对区域仍是第一版布局假设，不代表已实现任意布局识别。种族职业词表目前只有现有基础选项；不判断种族职业组合是否合法，不识别性别选中状态，不确认配置或建号成功。Windows OCR 没有为本工具提供可用置信分数，因此不展示虚假的百分比。

OCR 看见某个选项不意味着它已选中。弹窗正文未读清时显示“疑似对话框”，不能据此自动重试。未知页面保留原图供核对。截图中的文字只作为诊断数据，不会作为命令执行。
