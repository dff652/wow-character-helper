# 混合识别下一阶段

已确认方向：保留战网启动、规则集高亮核对、提交、已知阵营限制模板、退出和定时逻辑。局部 OCR 主要负责角色详情区可变文字；姓名输入本身不需要 OCR。

姓名校验优先级：验证是否能从游戏输入框准确读回文本；若不能，则验证局部 OCR 或保留人工核对。发送输入成功不能证明游戏接收、字段焦点和最终文本都正确。当前没有完成输入框读回实测，不移除现有校验，不承诺剪贴板复制或可访问性接口可用。

角色识别仍需区分可选项与选中状态，种族/职业组合需按客户端验证。只在这些检查有充分证据后解除逐配置校准。Windows OCR 已出现姓名误读，不允许用期望值强行纠正识别结果。

截至 2026-11-09，主工具为 v1.4.4-preview：已增加版本绑定的职业联动、组合执行白名单、人工重名处理、界面精简和无窗口启动恢复。诊断版 0.2.0 仍然独立，不参与自动提交。

待办顺序：补测真实残留恢复及完整重试循环；扩大可用组合与自动执行验证；验证角色详情 OCR 的选中状态识别；取得重名提示样本后实现分类；完成额外分辨率实测。每项保留样本与测试边界，不直接解除所有校准和白名单。
