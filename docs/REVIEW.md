实现者自审，非独立第三方评审。此次整理 README、版本历史、验证范围与计划，核对源码版本 1.4.4-preview，区分实际游戏测试与模拟回归。

- 残留恢复：完整路径、PID、启动时间共同核对；整个等待阶段不得出现可见窗口，超时仅尝试一次；清理失败不重复启动。详见 [启动修复说明](STARTUP-WINDOW-FIX.md)。
- 组合保护：职业可选表与自动执行白名单分离；不能把人工确认预览解释为所有组合自动化通过。

- 发布范围：源码、文档与识别小图；个人配置、运行日志、完整桌面截图和结果记录不提交。
- 验证：沿用本版本已经通过的五组检查及 13 项启动状态测试；此次只有文档修改，不重复操作游戏。

已知局限：前台输入、中文 WoW3、本机 4K 16:9 实测；自动清理仅模拟验证，本版未重新完成完整建号重试循环。不将当前预览版称为通用建号工具。

## 历史 v1.3.1 代码 review

2026-11-08，由实现代理进行自审与回归验证；不是独立第三方审计。

| 优先级 | 触发条件与影响 | 修复与验证 |
|---|---|---|
| P1 | 战网切换布局或停在其他 WoW 版本，固定位置模板找不到无限版入口 | 按可见无限图标定位并切换，再核对产品、WoW3 (CN) 和可用启动按钮；新旧布局分别实际启动到规则集页，通过 |
| P1 | 当前任务遇未知结果或用户停止后，其他到点任务可能继续抢占前台 | 停止/异常暂停自动调度，用户核对后从任务管理手动恢复；取消回归通过 |
| P2 | 单个任务 XML 损坏可能阻止任务页加载 | 坏文件保留、有效任务可读、报告错误并阻止自动调度；恢复前重新核对文件，通过 |
| P2 | 校准文件残缺，在进入执行循环前构造 Runner 抛错，可能保持界面锁定 | 初始化纳入 try/finally；任务标记需检查、界面解锁、调度暂停；注入残缺校准回归通过 |
| P2 | 残缺结果 XML 缺少配置时，结果页访问空对象 | 读取时校验并跳过残缺记录，原文件保留；回归通过 |
| P3 | 临时预览字体及取消源未完整释放 | 释放临时字体和取消源，清空已释放引用；窗口关闭和取消测试通过 |

核对了新增定位代码：操作前检查前台窗口及遮挡；定位过程定期检查取消；选择其他版本的页面不能直接通过产品核对；未找到控件时停止，不回退到猜测坐标。游戏进程仍按配置中的完整路径核对。

构建、配置/数据、布局、任务窗口、战网合成页面与私人截图回归通过。原始游戏流程与本轮启动测试的版本和范围见 [VALIDATION.md](VALIDATION.md)。

未发现本次改动中尚未处理的发布阻断问题。保留限制：仅当前中文 WoW3 入口实测；视觉匹配不能覆盖任意布局；未建立自动成功判定；需前台操作；计划任务到点到游戏提交未另做真实全链路验证。以上不能表述为“整个工具所有场景已跑通”。
