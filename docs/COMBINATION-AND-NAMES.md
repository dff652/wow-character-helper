# 组合规则与重名处理 · 1.4.1-preview

这是开发分支预览版，尚未合并主线。没有接入 OCR 自动提交或自动判定重名。

## 组合白名单

当前规则仅适用于无限服中文客户端 `1.60.1.70862`。执行前读取所配置 Wow.exe 的文件版本，版本不一致时停止。

| 组合 | 状态 | 依据 |
|---|---|---|
| 牛头人—德鲁伊 | 已核实 | 本机预览及实际提交已选中此组合 |
| 亡灵—德鲁伊 | 不支持 | 本机 PvP 界面按钮灰色，点击后仍为术士 |
| 其余组合 | 待验证 | 尚无足够已核实材料，不能套用其他版本的种族职业表 |

白名单并不完整。待验证不等于游戏不支持。

切换种族会移除明确不支持的职业；原职业不再适用时清空选择，要求重新选。待验证职业仍可选择并保存草稿，界面会解释状态；保存草稿不等于可执行。未知组合可以不提交预览，但即使做过旧式校准，也不会自动加入白名单。

已知非法组合在保存与预览前拒绝；未知组合在立即开始、任务创建、重新排期、执行旧任务及 Runner 入口拒绝自动执行。历史记录仅做结构检查，不因新规则隐藏。

## 重名流程

目前没有真实重名提示样本，自动检测尚未实现。未知结果仍按原有流程留档停止并暂停自动调度。

在游戏中明确确认重名后，在“结果记录”选择一条“待确认”记录，点击“确认重名并修改姓名”，确认对话框后：

1. 记录变为“重名待修改（人工确认）”，保留原主名、次名及截图。
2. 暂停自动调度，把这条记录的角色配置复制到配置页，并取消预约勾选。
3. 姓名框高亮，修改其中一个或两个名字。程序不自动添加后缀。
4. 保存并核对新配置后主动开始。旧式姓名校准尚未移除，改名后可能仍需不提交预览。

同一客户端版本、游戏路径和规则集下，被标记重名的同一主名＋次名不能再次开始或排期。仅改种族、性别或职业不能绕过此检查。当前战网仍仅适配 WoW3 (CN)，没有泛化为多账号姓名作用域。

旧定时任务保留旧配置快照，不会随配置页修改而自动更新；应取消旧任务，按新配置另建任务。人工标记重名不允许直接改为成功。

## 验证

构建、配置检查、六组布局、任务取消与异常恢复、战网匹配回归通过。新增检查包括：非法组合保存拒绝、未知组合草稿保存与执行拒绝、版本变化失效、职业联动清空、人工重名记录持久化、相同姓名阻止重试、改名不改写旧记录。

1.4.0-preview 的组合与重名功能未做游戏提交验证。随后 1.4.1-preview 通过 Computer Use 检查了 8 个基础种族的职业按钮及亡灵—德鲁伊的拒选行为，详见[界面组合检查](COMBINATION-INSPECTION.md)；没有提交建号，也没有扩大自动执行白名单。自动重名识别、完整组合执行验证、去除逐姓名校准仍未完成，不能把本版本称为通用建号工具。
