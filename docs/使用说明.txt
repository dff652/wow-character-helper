无限服建号助手 v1.3.0
作者：dff652；开发协助：OpenAI Codex
源码：https://github.com/dff652/wow-character-helper

启动与配置
Windows 10/11 64 位，.NET Framework 4.8。完整解压运行 RetryPvp.exe，保留 RetryPvp.exe.config 和 templates。
战网需保持已登录，显示“无限” WoW3 (CN) 的进入游戏按钮，保持采样时窗口尺寸与布局。
默认角色：PvP / 部落 / 牛头人 / 男性 / 德鲁伊；主要名字“歪瑞歪瑞”，次要名字“古德”。
可设置规则集、阵营、8 个基础种族、性别、职业及两个名字。没有外观配置。
修改角色信息后，先点“预览校准（不提交）”，核对截图中的实际属性与名字，确认一致才保存校准。此步骤不会点击完成。
种族可用职业由游戏决定，灰色或未解锁组合不应确认校准。其他组合尚未逐一实测。
保存配置后下次打开自动载入。运行时参数锁定；F9 停止后可以修改和切换模式。

两种模式与定时
1. 识别阵营限制 → 正常退出游戏 → 等待 → 从战网重进 → 重选规则集 → 重新建角提交。
2. 识别阵营限制 → 保持游戏并等待 → 返回规则集 → 重选 → 重新建角提交。
两种模式均不会原地连续点击完成。
默认间隔 120 秒、最多 60 次、最长运行 0 分钟（不限时）。次数或时长先达到即停止。
模式一的等待从游戏退出后开始，模式二从识别拦截后开始，不是固定整点提交。
可预约开始时间；工具须保持运行、电脑唤醒、屏幕解锁。关闭工具取消本次任务。
F8 或开始按钮启动，F9 / Esc 停止。操作期间不要切换窗口或使用鼠标键盘。等待期间可切换应用，下轮自动切回。
游戏主窗口关闭后，若同一游戏进程残留 30 秒，会清理该残留进程；主窗口仍在则停止。

文件夹
所有运行数据集中在程序旁的 data 中：
data/config：建号配置.xml
data/logs：按日期保存的运行日志、错误日志、迁移日志
data/results：每轮尝试的 XML 记录及截图
data/screenshots：调试截图和最后结果
data/profiles：人工核对后的校准样本
旧根目录配置、日志、调试图、records 和 profiles 首次运行自动迁移，不覆盖同名数据；冲突旧文件保存在 data/legacy。
旧记录即使保存了旧的绝对截图路径，也会在新位置按文件名查找。
环境设置可打开数据目录，日志页与结果页也有对应打开按钮。
说明和测试结果在 docs，源码在 GitHub 的 src，构建脚本在 scripts。运行包不含个人数据。

结果记录
每轮准备提交前先留档，随后更新结果。保存配置快照、姓名、时间、轮次与截图。
被拦截：识别到已采样的阵营人口不平衡提示。
待确认：准备提交后尚无明确结果，或提交后未识别到已知拦截。可能成功、重名、其他错误或中断，不代表成功。
成功（人工确认）：在游戏中核对角色确已创建后，点击“确认已建号成功”，保存确认时间。
没有经过实测的自动成功识别。约 35 秒未识别到已知拦截时会停止，不再自动尝试。
中断可能仅保留提交前截图，请结合详情核对请求是否送达。关闭工具不会删除历史记录。

分辨率和显示缩放
工具标题和表单改用随内容增高的布局，启用每显示器 DPI。窄窗口上下排列并可滚动。
已进行 100%、125%、150%、200% 的控件缩放模拟检查，含 1280×720 至 3840×2160；这不等于所有显示器实机验证。
游戏按客户区换算坐标，要求接近 16:9、至少 1280×720，且游戏 UI 布局和缩放与采样一致。
只有本机 4K 游戏画面完成两种循环实测；1080p、1440p 尚未做真实游戏端到端验证。
超宽屏、4:3、其他界面布局不保证兼容。战网入口仍依赖采样尺寸和 WoW3 布局。
修改显示设置后先做不提交预览；普通建角预览不能代替战网启动入口验证。
多显示器不同缩放热切换尚未实机验证，异常时关闭并在目标显示器重开工具。

验证与边界
两种循环此前各实测 2 轮，全部被服务器阵营限制拦截，未创建成功。
本次目录迁移、配置、记录、旧截图路径解析和窗口布局检查通过；没有再次提交建号。
工具只处理已识别的阵营限制。未知提示、失去前台、登录、验证码、更新等需要用户处理。
已有角色的列表页面尚未适配。修改程序路径不代表适配其他账号或客户端。
v1.2.0 显示与进度
环境设置 → 画面与布局，默认自动识别实际游戏客户区。可选标准 16:9 自动分辨率或指定 1920×1080、2560×1440、3840×2160。手动选项仅用于校验，不改变游戏设置；不支持的比例停止。
窗口底部显示实际阶段、运行耗时、尝试次数、拦截次数、下次开始倒计时。停止后保留原因和耗时。逐页截图保存在 data/screenshots，按会话时间和步骤排序。

任务管理
先在建号与定时、环境设置中选择配置，再到任务管理填写名称和计划时间，保存为定时任务。任务保存配置快照。支持立即启动、停止/取消排期、重新排期和删除。任务文件在 data/tasks。多个到点任务排队串行运行。工具关闭期间错过的计划不会补跑，异常中断需手动启动。已完成仅表示执行结束，不代表建号成功。

流程节点
配置下方显示九个流程节点。蓝色是进行中，绿色是动作完成，橙色是被拦截或待确认，红色是停止或异常，灰色是未开始或无需执行。点击节点查看动作与次数，悬停查看完整详情。耗时为本次运行内该节点多次执行的累计耗时；停止后冻结。绿色不表示角色创建成功。
