# 版本历史

## 1.3.2 — 2026-11-08

- 修复底部按钮和状态区保留过多高度、挤压上方滚动内容的问题。按钮采用自动换行，底部高度按实际内容计算。
- 增加六组尺寸和缩放下的缩窄/放大回归检查，核对底部没有多余留白。
- 本次不更改游戏操作、姓名校验或配置校准规则。通用识别继续在开发分支验证。


## 1.3.1 — 2026-11-08

- 修复战网布局/版本切换后的入口识别：自动选择无限图标，分别核对新旧布局的产品、账号和按钮。两种布局实际启动到规则集页通过。
- 停止或异常后暂停自动任务调度，增加手动恢复；损坏任务文件保留并报告，不执行剩余队列。
- 修复初始化失败后的界面锁定，隔离缺少配置的结果记录，释放取消源与预览临时字体。
- 增加异常路径、入口匹配回归及验证范围/review 文档。未新增建号提交。

## 1.3.0 — 2026-11-08

- 移除首页版本作者行，放大区域内文字与原生输入控件字体。
- 新增九阶段流程节点，展示实际动作、状态、累计耗时、执行次数与停止原因。
- 节点可点击查看详情，窄窗口自动换行并滚动；进行中仍可查看节点。
- 验证节点计时、停止冻结、重复累积与拦截状态保留；本次未再次提交建号。

## 1.2.0 — 2026-11-08

- 新增任务管理：独立配置快照、一次性排期、立即启动、停止、重新排期和删除；中断与过期计划不自动补跑。

- 修复高 DPI 后台线程尺寸虚拟化引起的截图截断。
- 默认自动检测游戏实际尺寸，提供标准 16:9 与固定分辨率手动选择。
- 新增阶段状态、耗时、轮次、拦截次数和重试倒计时。
- 页面状态变化保存诊断截图，启动失败记录实际前台窗口名称。
- 启动过程中兼容同一游戏/战网进程的附属窗口。

## 1.1.0 — 2026-11-08

- 运行数据集中保存至 data/config、logs、results、screenshots、profiles。
- 自动迁移旧版根目录数据；同名冲突保留两份；迁移后的记录截图可继续打开。
- 标题栏、首页和关于页显示版本与作者；EXE 文件属性写入相同版本信息。
- 用随内容增高的布局替换固定高度标题和表单行，修复字体缩放时的遮挡。
- 窄窗口改为上下排列并提供滚动，底部开始/停止按钮保持可见。
- 配置 .NET Framework 4.8 的 PerMonitorV2 DPI 支持，并明确游戏与战网的兼容范围。
- 新增关于与兼容性页、打开数据文件夹和日志文件夹按钮。
- 增加迁移、数据持久化、六组窗口与缩放模拟检查。

## 1.0.0 — 2026-11-08

初始配置与记录版本：两种定时模式、角色预览校准、可保存配置、提交前留档与人工成功确认。
