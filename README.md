# 无限服建号助手 · WoW Character Helper

版本 **1.1.0** · 作者 **dff652** · 开发协助：OpenAI Codex

Windows 图形工具：配置角色、按间隔重新选择规则集并尝试建号、保存本地结果。

## 功能

- 配置规则集、阵营、8 个基础种族、性别、职业、主名与次名。
- 两种重试模式：退出游戏后从战网重进，或保留游戏并返回规则集重选。
- 设置间隔、最多尝试次数、最长运行时间、预约开始时间；F8 开始，F9 / Esc 停止。
- 修改角色信息后，先进行**不提交建号**的预览校准，并核对实际游戏选项。
- 每轮提交前留档，保存配置快照、时间、轮次与截图。未识别到已知拦截时停止。
- 记录状态为“被拦截”“待确认”“成功（人工确认）”。**没有经过验证的自动成功识别**。

## 使用

运行环境：64 位 Windows 10 / 11，.NET Framework 4.8。

1. 完整解压运行包，运行 `RetryPvp.exe`，保留旁边的 `RetryPvp.exe.config` 和 `templates`。
2. 战网保持登录，显示“无限” WoW3 (CN) 的进入游戏按钮。
3. 检查角色配置与重试模式。默认角色为 PvP / 部落 / 牛头人 / 男性 / 德鲁伊，主名“歪瑞歪瑞”，次名“古德”。
4. 修改角色或姓名后，先预览核对，再开始运行。
5. 操作期间保持游戏或战网在前台，不操作鼠标键盘。等待期间允许切换应用，下一轮自动切回。

只对已识别的“阵营人口不平衡”提示自动重试。未知结果停止，并由用户查看游戏确认。工具不绕过服务器限制。

预约需要程序持续运行、电脑保持唤醒、屏幕解锁。关闭工具会取消当前预约和重试。

## 文件保存

```text
RetryPvp.exe
RetryPvp.exe.config
templates/                 内置识别模板
docs/                      说明、版本历史与测试范围
data/                      首次运行创建，不随发布包分发
  config/                  建号配置.xml
  logs/                    按日期保存的运行日志、迁移日志、错误日志
  results/                 每次尝试的 XML 记录和结果截图
  screenshots/             调试截图与最后结果
  profiles/                人工核对后的角色校准样本
  legacy/                  仅在迁移同名冲突时创建，保留旧文件
```

从旧版覆盖升级前先关闭旧工具。新版首次运行会迁移旧根目录配置、日志、调试图及 `records` / `profiles`，不覆盖同名数据。旧记录中的截图路径会按新位置解析；整个程序文件夹搬家后仍可查看。迁移不改动角色配置。

源码仓库另外包含 `src/` 和 `scripts/`。个人配置、运行日志、完整游戏截图与结果记录不提交到仓库。

## 分辨率与缩放：有边界的适配

| 范围 | 现状 |
|---|---|
| 工具窗口 | 启用每显示器 DPI，标题与说明自动增高；窄窗口上下排列并可滚动 |
| 布局检查 | 在 100%、125%、150%、200% 下模拟控件缩放，含 1280×720 至 3840×2160 的窗口限制；这不是各型号显示器实测 |
| 游戏识别 | 按游戏客户区换算为 2560×1440；要求接近 16:9、至少 1280×720，且界面布局和缩放保持一致 |
| 已完成的游戏实测 | 本机 4K 画面、中文客户端、空角色列表，两种模式各 2 轮，均被阵营限制拦截 |
| 1080p / 1440p | 有坐标换算机制，但尚未完成真实游戏全流程验证，不能据此承诺直接可用 |
| 超宽屏 / 4:3 / 界面改版 | 不保证兼容；比例不符时停止，不能靠拉伸可靠识别 |
| 战网入口 | 仍依赖本机采样的 WoW3 入口、窗口尺寸与布局；重启模式并非任意屏幕即用 |
| 多显示器不同缩放热切换 | 尚未实机验证；异常时关闭工具并在目标显示器重新打开 |

换显示设置后请先做不提交预览。普通预览只核对游戏建角页面，不能替代战网启动入口实测。其他规则集与角色组合没有逐一验证。

DPI 配置参考 [Microsoft 的 Windows Forms 高 DPI 文档](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms)。

## 从源码构建

在 Windows PowerShell 中执行：

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
```

使用系统自带的 .NET Framework C# 编译器，无需 Python、AutoHotkey 或第三方包。构建结果在 `dist/`。验证数据在 `test-output/`，均被 Git 忽略。

`test.ps1` 检查配置保存、结果持久化、旧目录迁移与冲突保留、模拟窗口布局；不会操作游戏或提交建号。
已有私人截图的离线识别回归入口为 `RetryPvp.exe --test <截图目录>`，截图不包含在公开仓库。
